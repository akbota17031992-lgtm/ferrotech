# ТОО «Ferrotech Kazakhstan» — Промышленный портал металлопроката и спецсплавов в РК

Специализированный B2B-портал для казахстанского рынка (аналог `bvbalyans.kz`, `gkws.kz`, `specmet.kz`), адаптированный под требования законодательства Республики Казахстан (НДС 12%, ЭСФ, СНТ, БИН, сертификаты СТ-KZ).

---

## 🇰🇿 Особенности казахстанской локализации:

1. **Валюта и налогообложение:**
   * Все цены в каталоге, калькуляторе и КП указаны в **тенге (₸ / KZT) с учетом НДС 12%**.
   * Форма выставления счетов принимает **БИН (12 цифр)** и наименование ТОО/ИП.
   * Полная поддержка требований порталов Госзакупок РК (`goszakup.gov.kz`) и фонда «Самрук-Қазына».

2. **Складская и филиальная сеть по Казахстану:**
   * **Астана** — Главный логистический комплекс (Индустриальный парк №1).
   * **Алматы** — Склад цветных металлов, тонкостенных нержавеющих труб и сортового проката (пр. Рыскулова).
   * **Караганда** — Склад конструкционных и инструментальных сталей, поковок и чугуна для горнорудных комбинатов.
   * **Атырау** — Склад коррозионно-стойких и жаропрочных сплавов (титан, AISI 316L, фланцы) под нефтегазовые проекты Тенгиз и Кашаган.
   * Представительства в Шымкенте, Актобе, Актау, Павлодаре, Усть-Каменогорске и Костанае.

3. **Инженерные инструменты:**
   * **Калькулятор массы металлопроката** для 10 форм проката (лист, круг, труба круглая, профильная, полоса/шина, квадрат, шестигранник, уголок, швеллер, проволока) с автоматическим пересчетом в тенге.
   * **Калькулятор стоимости услуг резки в размер** (лазерная резка, гидроабразив, ленточнопил, плазма).
   * **Инженерная карточка товара** с химическим составом по ГОСТ/СТ РК (% C, Cr, Ni, Ti, Cu, Mo).
   * **Экспорт прайс-листа в Excel / CSV** с кодировкой UTF-8 BOM для казахских и русскоязычных названий.
   * **Печать официального коммерческого предложения (КП)** в PDF с фирменным бланком и реквизитами.

## 💻 Как открыть и запустить проект:

### Вариант 1 (Без серверов, прямо с диска — мгновенный просмотр):
Просто откройте файл **[`index.html`](index.html)** двойным щелчком в браузере (Chrome, Edge, Яндекс.Браузер).

### Вариант 2 (Через локальный Node.js сервер на свободном порту 8088):
```powershell
node server.js
```
И откройте в браузере: **`http://localhost:8088`**
* Сервер автоматически сохраняет все поступающие заявки и звонки в файл [`leads.json`](leads.json).

### Вариант 3 (Публичная ссылка через туннель с автопереподключением):
```powershell
npm run tunnel
```
Запускает защищенный туннель с keep-alive пингами каждые 15 сек, ссылка выводится в консоль и сохраняется в `tunnel-url.txt`.

## 📁 Структура файлов проекта:

* [`index.html`](index.html) — разметка портала, каталог, калькуляторы, модальные окна заявок.
* [`styles.css`](styles.css) — стили, адаптивность под мобильные устройства, стили печати PDF/КП.
* [`app.js`](app.js) — база товаров в тенге ₸, формулы калькуляторов, поиск, экспорт в Excel.
* [`server.js`](server.js) — легковесный локальный сервер на чистом Node.js (порт 8088).
* [`leads.json`](leads.json) — база сохраненных клиентских заявок.
* [`package.json`](package.json) — скрипты запуска.
